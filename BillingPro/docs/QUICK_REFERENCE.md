## KEYBOARD SHORTCUTS
| Key | Action |
|-----|--------|
| F2 | Save & Print |
| F3 | Save Only |
| F5 | Reset Form |
| F12 | Add Item |
| Enter | Next field |
| Tab | Navigate |
| Esc | Cancel |

## BILLING WORKFLOW
1. Enter item description
2. Press Tab → Enter quantity
3. Press Tab → Enter rate
4. Press Enter → Item added
5. Repeat for more items
6. Enter discount (if any)
7. Enter amount received
8. Press F2 → Save & Print

## THERMAL PRINTER SETUP
1. Connect printer via USB
2. Install Zadig → Replace driver with WinUSB
3. Go to Settings → Printer → Test Print
4. If test works, you're ready!

## UPI QR SETUP
1. Go to Settings → Shop Settings
2. Enter your UPI ID (e.g., shop@upi)
3. QR will auto-generate on every bill

## BACKUP
- Auto backup runs daily
- Manual: Settings → Backup → Create Backup
- Restore: Settings → Backup → Restore
